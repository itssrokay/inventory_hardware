# ADR-006: Use discounts as a one-time selling-price calculator

- Date: 2026-11-06
- Status: Accepted

## Context

The user wants calculations such as 25% off while the product model retains one selling price per variant.

## Decision

Accept an optional 0–100% discount with up to two decimal places on item entry and quick price edit. Compute the rounded net amount in integer paise and save it as the selling price. Reopening an edit starts with the saved net amount and an empty discount field.

**Alternatives considered**

- Persist a base price and a recurring discount rule alongside each selling price: deferred because it adds pricing states and could accidentally reapply discounts.

**Consequences**

- No database migration or backup-format change is needed. Price history records actual net-price changes; the percentage itself is not retained as a separate pricing rule.
