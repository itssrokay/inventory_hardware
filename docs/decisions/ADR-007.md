# ADR-007: Keep manufacturer references separate from carried shop variants

- Date: 2026-11-06
- Status: Accepted

## Context

The shop carries only part of a 92-page manufacturer pricelist. List rates, pack details and product codes do not prove stock or establish shop selling prices.

## Decision

Bundle a provenance-rich JSON library separately from Room and IndexedDB shop products. All reference variants start stock unconfirmed and hidden from shop search. Activation opens blank price and unit fields; saved variants retain unique stable source IDs. Preserve the PDF, source dates, printed headings and flagged anomalies. Android schema 2 migrates existing data; backup version 2 retains reference links and accepts legacy version 1.

**Alternatives considered**

- Seed all source products into the shop catalog: rejected because it would imply availability and clutter counter searches.
- Treat a supplier SKU or list rate as a unique shop product and selling price: rejected because codes repeat across source contexts and rate units vary.

**Consequences**

- The owner must choose carried variants and confirm specifications, selling units and prices. No quantity is created, and carried means a shop selection rather than a live stock count.
- The original PDF and generated source page images stay local and Git-ignored; recreating those views on another checkout requires the source PDF and the documented import command.
