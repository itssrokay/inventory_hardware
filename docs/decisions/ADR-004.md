# ADR-004: Share one workflow and keep project memory in the repository

- Date: 2026-11-06
- Status: Accepted

## Context

The user wants project-specific guidance for multiple coding agents and an easy way to revisit completed work, architecture and decisions.

## Decision

Keep AGENTS.md as the shared instructions, import it from CLAUDE.md and link Claude’s skill path to the canonical .agents skill. Store append-only outcomes and ADRs in docs/events.jsonl, maintain the current snapshot in docs/project.json and render Markdown plus a read-only localhost cockpit.

**Alternatives considered**

- Maintain independent Codex and Claude instruction copies: avoided because their rules and context would drift.
- Use chat transcripts or an external project service as the only memory: avoided because they are harder to skim and would require extra accounts or tool access.

**Consequences**

- Both agents can use the same local workflow, but instructions guide behavior rather than enforce it. Agents must actually log meaningful completed work and keep the snapshot current.
- The journal helper uses a POSIX file lock on Mac/Linux; Windows checkouts need a compatible environment and care with the skill symlink.
