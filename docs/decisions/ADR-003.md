# ADR-003: Keep the web build as a separate local preview

- Date: 2026-11-06
- Status: Accepted

## Context

After the Android build, the user asked for a localhost web version to quickly look around.

## Decision

Use a dependency-free Node server and HTML/CSS/JS frontend on loopback. Persist the preview catalog in browser IndexedDB and reuse the Android AI prompts/schemas.

**Alternatives considered**

- Build shared cloud storage and Android/browser synchronization now: outside the requested preview scope.
- Serve the repository directory directly: rejected because local configuration and credentials must not be exposed.

**Consequences**

- Android ZIP and browser JSON backups are separate formats, and users must not assume the catalogs synchronize.
