# ADR-005: Route image entry and AI categories through editable review

- Date: 2026-11-06
- Status: Accepted

## Context

The user wants to add items from images, crop them and have AI intelligently categorize products.

## Decision

Crop, position, zoom and rotate locally. Send only the accepted crop with an explicit Review items or Suggest category action, using Responses vision inputs and strict schemas. Missing prices remain blank; category and alias suggestions update drafts only. A single-item input can supply its product photo.

**Alternatives considered**

- Upload the original image as soon as it is selected or save recognized items automatically: rejected because users need control of both the submitted region and catalog changes.

**Consequences**

- Image recognition and category suggestions need internet and an API key. Manual entry, local cropping and local search remain available offline. Real-world recognition still requires user review.
